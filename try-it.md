# Try it: free sites where you practise in the browser

Learn cards ask you to **try** each new idea for 15 to 20 minutes. These free sites let you do that in a browser, with nothing to install.
Every address was checked on 10 November 2026 and opened with status 200.
A site that needs an account says so in its row.

## Python

| Site | Address | Use it for |
|---|---|---|
| Python Tutor | https://pythontutor.com/visualize.html | Run Python one line at a time and watch the variables, lists and function calls change. Paste code that confuses you. |
| futurecoder | https://futurecoder.io/ | A free Python course for complete beginners, with exercises and hints, in the browser. |
| Exercism Python track | https://exercism.org/tracks/python | Short practice problems with tests, and free mentor feedback. Needs a free account. |

| vite.new (StackBlitz) | https://vite.new/react-ts | A complete Vite React TypeScript project in the browser. Works best in Chrome or Edge. |

## SQL and databases

| Site | Address | Use it for |
|---|---|---|
| SQLBolt | https://sqlbolt.com/ | Short SQL lessons, each with an exercise you type into the page. Start with lesson 1, `SELECT`. |
| W3Schools SQL Try it editor | https://www.w3schools.com/sql/trysql.asp?filename=trysql_select_all | Run any SQL query on a small shop database, and change it freely. |
| PostgreSQL Exercises | https://pgexercises.com/ | Practice questions for joins, `GROUP BY` and dates, on a real PostgreSQL database. |
| SQL Murder Mystery | https://mystery.knightlab.com/ | A detective game that you solve by writing SQL queries. |
| PGlite REPL | https://pglite.dev/repl/ | A real PostgreSQL that runs inside your browser tab. |
| DB Fiddle | https://www.db-fiddle.com/ | Make tables, run queries and share the result as a link. Choose PostgreSQL from the database list. |
| explain.dalibo.com | https://explain.dalibo.com/ | Paste the output of `EXPLAIN ANALYZE` and see the query plan as a diagram, with the slowest step marked. |
| dbdiagram.io | https://dbdiagram.io/d | Draw an ER diagram by typing tables and their links as text. |
| Mermaid Live Editor | https://mermaid.live/ | Draw diagrams from text: `erDiagram`, `flowchart` and `sequenceDiagram`. If a diagram renders here, it renders on GitHub too. |
| Mongo Playground | https://mongoplayground.net/ | Run MongoDB queries and aggregations on sample documents. |

## Text, data and security

| Site | Address | Use it for |
|---|---|---|
| regex101 | https://regex101.com/ | Build and test a regular expression on your own text. Choose the **Python** flavour; the page explains each part. |
| RegexOne | https://regexone.com/ | Step-by-step regular expression lessons with exercises. |
| jq play | https://play.jqlang.org/ | Pick fields out of JSON with `jq` filters. |

| OWASP Juice Shop | https://owasp.org/www-project-juice-shop/ | A deliberately insecure web shop for practising security testing. It runs on your laptop: `docker run --rm -p 3000:3000 bkimminich/juice-shop`, then open http://localhost:3000. The download is about 120 MB. |
