This folder is a `railseat/` product folder with the set-up already done: project files, folder layout, configuration, test set-up, types and function signatures. All the logic that a task asks for is still yours. Each piece is marked `TODO(task NN)`, where NN is the task's number in module P3.

## Copy it in (task 8)

In Git Bash, in task 8's folder, before you have a `railseat/` folder there:

```bash
cp -r ~/fspy-v3-kit/starters/p03-railseat-api railseat
```

Then do task 8 in `railseat/docs/erd.md`. From task 9 on, copy your `railseat/` folder forward, as every brief says.

## Run it

In `railseat/api/`:

```bash
uv sync                          # makes .venv/ from uv.lock
uv run pytest                    # 1 passed, 3 skipped until task 12
uv run fastapi dev app/main.py   # then open http://localhost:8000/docs
```

Until you write them, the endpoints answer 500, and the terminal shows `NotImplementedError: TODO(task NN)`. Alembic, the loader and the task 12 tests need the cloud lab's PostgreSQL: run `docker compose --profile core up -d` in `~/fspy-v3-kit/cloudlab` first.
